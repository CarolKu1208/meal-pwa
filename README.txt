餐補小幫手 PWA 原型（手機排版修正版）

狀態：測試版，尚未正式可用。
修正：欄位改為 minmax(0,1fr)、窄螢幕單欄、限制橫向溢出、統計卡片自動換行、加入安全區底部留白。
功能：單日查詢、員工編號本機記憶、每日上限估算、7-ELEVEN 85 折估算。

重要：
1. API 路徑目前使用 /reports/employeesDiningRecords，但尚未以成功 API 回應驗證。
2. CORS 尚未驗證；若瀏覽器擋下請求，需由後端代理呼叫 API。
3. 這個版本仍由前端直接呼叫 API，僅供測試，不應公開分享正式使用。
4. 員工編號記憶在本機瀏覽器 localStorage，清除網站資料後可能消失。
5. 每日上限與 7-ELEVEN 估算規則需以公司正式政策核對。
